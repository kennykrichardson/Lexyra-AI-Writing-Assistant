# Lexyra frontend\n\nReact + TypeScript + Vite frontend for the existing Lexyra FastAPI backend.\n\n## Run locally\n1. Install Node.js 20+.\n2. Run `npm install`.\n3. Copy `.env.example` to `.env.local` and set `VITE_API_BASE_URL` to your backend URL.\n4. Run `npm run dev`.\n\nBuild with `npm run build`. The frontend calls `GET /api/health` and `POST /api/enhance`. Keep Cloudflare credentials in the backend only.\n
